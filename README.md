**Bowborne**

This project is made as an intake assignment for Breda University of Applied Sciences.\
It is made in C++ with SFML and Box2D.

The goal of Bowborne is to shoot the enemy off the platform.\
You have limited arrows, so you must carefully shoot them towards the enemy.\
How high of a score can you get?

Controls:\
Left Click = Shoot Arrow\
Escape: Enable / disable Main Menu (game pauses when main menu is active)

The bow follows the mouse position, so arrows will shoot towards your mouse cursor.\
The further the mouse position is from the player, the more force the arrow receives once shot.
